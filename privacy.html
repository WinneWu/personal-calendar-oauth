隱私權政策

最後更新：2026 年 8 月 22 日

適用範圍處理的資料使用目的儲存與保留分享與揭露使用者控制聯絡方式

1. 適用範圍

本政策適用於「個人日曆同步工具」（以下稱「本工具」）。本工具僅供擁有者本人使用，目的為將使用者自行指定來源中的日程資料同步至其所擁有的 Google Calendar；不提供一般大眾註冊。

2. 本工具處理的資料

2.1 Google Calendar OAuth 資料

  • 使用者可用的日曆清單及目標日曆資訊（唯讀）。
  • 目標日曆中由本工具建立或比對的活動資訊。
  • OAuth 存取權杖與更新權杖，用於在授權有效期間呼叫 Google Calendar API。

2.2 使用者指定的來源資料

本工具可透過使用者另外設定的本機資料連線，讀取指定來源中的日程資訊，可能處理：

  • 日期、起訖時間、類別、時數、說明與來源編號。
  • 來源標題、訊息識別碼、關聯資訊、建立時間及處理狀態。
  • 使用者指定的日程狀態。

Calendar OAuth 本身不授予本工具其他 Google 服務的 API 權限；其他資料來源與 Calendar OAuth 為分開設定的本機整合。

3. 資料使用目的

上述資料僅用於：

  • 辨識需要同步的有效日程資料。
  • 避免同一筆來源資料被重複建立。
  • 建立或更新包含日期、時間、類別、說明與狀態的 Calendar 活動。
  • 在同步成功後更新來源資料的處理狀態。
  • 維護授權、排除錯誤及保障同步安全。

4. 儲存、保留與安全

  • 本機處理：OAuth 憑證與權杖儲存在使用者自己的裝置，並使用受限制的檔案權限保護。
  • 來源資料：仍保留於使用者自行設定的來源；本工具不另建遠端資料庫。
  • Calendar 活動：保留於使用者選定的 Google Calendar，直到使用者修改或刪除。
  • 執行資料：日程資料在同步程序中暫時處理；操作記錄可能保留執行時間、動作結果、來源編號或事件識別碼，以供故障排除，但不以完整來源內容作為一般操作記錄。
  • 權杖期限：權杖保留至使用者撤銷授權、刪除本機憑證，或 Google 使其失效為止。

5. 分享、移轉與廣告

本工具不出售 Google 使用者資料、不用於廣告投放、不建立廣告輪廓，也不將資料用於訓練通用 AI 或機器學習模型。除下列情況外，不會向第三方揭露資料：

  • 依使用者指示將日程資訊寫入其選定的 Google Calendar。
  • 為遵守適用法律、法令或合法政府要求所必要。
  • 為防止詐欺、濫用或安全事件所必要，且揭露範圍限於處理該事件所需。

本工具對 Google API 資料的使用與移轉，遵守 Google API Services User Data Policy，包括其 Limited Use 要求。

6. 使用者的選擇與控制

  • 可在 Google 帳戶的第三方連線頁面隨時撤銷本工具的存取權。
  • 可刪除本機 OAuth 權杖，使本工具停止存取 Calendar。
  • 可在 Google Calendar 檢視、修改或刪除同步產生的活動。
  • 可停止本機排程或移除來源連線設定，停止後續處理。

7. 政策變更

若本工具的資料類型、用途或權限範圍有重大變更，本頁將更新內容與「最後更新」日期。必要時，使用者會在重新授權前看到新增的 OAuth 權限。

8. 聯絡方式

如對本政策、資料處理或權限撤銷有疑問，請透過應用程式擁有者提供的既有聯絡管道，或使用本網站所屬 GitHub 儲存庫的 Issues：

前往 GitHub Issues →部署至 GitHub Pages 後，此處會自動顯示儲存庫聯絡連結。
